An AI-powered web application that helps users plan and structure websites based on their requirements. It generates website layouts, content suggestions, and development guidance using AI.

---

## ✨ Features

- 🏗️ Website structure generation
- 🤖 AI-powered content suggestions
- 📝 User requirement analysis
- 🚀 Development planning assistance

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/kunal-sahu1122/AI-Website-Planner.git
cd AI-Website-Planner
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
python backend/main.py
```

Follow the terminal output for the local application URL.
