# AI Website Planner

AI Website Planner is an intelligent web application that helps users plan and structure websites based on their requirements. It generates website layouts, content suggestions, and development guidance using AI.

## Features

* Website structure generation
* AI-powered content suggestions
* User requirement analysis
* Development planning assistance

## Tech Stack

* Python
* Flask
* HTML
* CSS
* JavaScript

## Project Structure

backend/
frontend/
requirements.txt

## Installation

pip install -r requirements.txt

python backend/main.py
